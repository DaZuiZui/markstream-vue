# Search

This site uses VitePress local search.

## How to use it

- Click the search box in the top-right corner and type a keyword to search the docs in the current language
- Desktop shortcut: `⌘ K` (macOS) / `Ctrl K` (Windows / Linux) opens the search modal

## Tips

- If a page does not show up, double-check the language first (English and Chinese docs live under `/` and `/zh/`)
- Search works best for component and function names — try `MarkdownRender`, `enableMermaid`, `enableKatex`, and similar keywords
